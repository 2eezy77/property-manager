# Agent notes

## Cursor Cloud specific instructions

- **Product:** Montero Rentals property manager — Express API (`npm run dev`, port 8080) + React/Vite client (`cd client && npm run dev`, port 5173). Production is Railway serving `client/dist` after `npm run db:migrate` (`railway.json` preDeploy).
- **Database:** Use Railway/`DATABASE_URL` (Supabase session pooler). Do not wipe or re-seed production tenants. Local `.env.local` often points at localhost Postgres and may set `EMAIL_ENABLED=false` — `src/config/env.js` prefers already-set host env over `.env.local`, so prefer `railway run …` (or export Railway vars) when hitting prod/staging Supabase.
- **Payments:** Card and Cash App Pay charge tenants **2.9% + $0.30** (`src/services/payment-processing-fee.service.js`); ledger `payments.amount` stays the base rent/deposit. ACH has no fee. Client estimates in `Payments.jsx` / `FinishLeasePay.jsx` must match that formula; server is source of truth at create-intent time.
- **Native VA leases:** Status path `draft → pending_tenant_signature → pending_manager_signature → awaiting_deposit → awaiting_identity → active` (identity step skipped only if already verified before deposit). Migration `041_native_va_lease.sql` is additive. QA: `npm run test:native-lease:all` (API test needs running DB + Stripe test keys). Do not commit generated PDFs under `documents/`. Native **room** leases share a house unit — Create Lease must list occupied units when path is Native (legacy whole-unit leases still hide occupied).
- **Stripe Identity:** Native lease deposit activation is gated on `tenant_identity_verifications.status = 'verified'`; without it, deposit settlement leaves the lease in `awaiting_identity`. Tenant-paid fee base is $1.50 + card/Cash App processing fee. `IDENTITY_PII_ENCRYPTION_KEY` must be a 32-byte base64 key. Cloud host secrets may inject `sk_live` over `.env.local`; for local Identity demos start the API with TEST keys via `scripts/start-api-stripe-test.sh` and forward webhooks with `stripe listen`. Stripe TEST often redacts SSN digits — app fail-closes without a 9-digit id_number; LIVE returns digits for encryption. QA: `npm run test:identity:all`.
- **Lease invite:** `POST /api/leases/native` with `invite: { email, first_name, phone, last_name? }`. When `EMAIL_ENABLED=false`, invite email is skipped (`inviteReason: disabled`) and the reset token is not kept — set a password on the invited user for local login QA.
- **Standard commands:** See root `package.json` / `SETUP.md` / `README.md` for migrate, seed, smoke, and portal scripts. Useful checks: `npm run test:processing-fee`, `npm run test:balance-paid`, `npm run assert:portal-pay`.
- **Former tenants / rent archive:** Monthly rent+deposit CSVs live under `archive/rent-by-month/` (one file per month). Mark former-tenant payment rows with `metadata.archived_former_tenant=true`. Set `users.site_archived_at` to hide them from **all** live site lists (Tenants, Leases, Payments, Inbox, Admin). **Davontaye Tyrrell Gara** is site-archived; rent history under `2026-06.csv` only.
- **Collections notices:** Do **not** put former tenants on Manager Payments. Append rows to `archive/collections/notices.csv` (see that folder’s README). The live rent roster no longer shows a Collections panel.
- **Flexible rent (Stone):** Buckley Stone’s lease has `late_fee_amount=0` and `grace_period_days=31` — he may pay anytime in the month with no late fees. Rent roster shows partial balance without Late/email. Migration `043_skip_zero_late_fees.sql` skips fee inserts when `late_fee_amount` is 0.
- **Superseded failed payments:** Ledger/rent-status hide `failed` rows when any `succeeded` payment exists for the same lease + `payment_type` + billing month, regardless of method (ACH, card, Cash App, offline). See `src/utils/payment-ledger.js`.
- **Utility house cover (743):** `properties.utility_house_cover_per_tenant` (seeded `$100` for 743 A Ave). Monthly pool = `max(0, combined − $100 × active leases)`; see `src/use-cases/utilities/house-cover.js` and migration `045`. After deploy, run Manager **Recalculate splits** (or `npm run utilities:recalc-splits:apply`) so open months pick up cover.
- **Dominion electric cycles:** Not calendar months. Prefer **Current Charges** over Total Account Balance (`src/services/dominion-billing.service.js`). Period = statement date minus `(billing_days − 1)` through statement date. House-cover month keys off **`period_end`** (statement month), not `period_start`. Owner exports under `archive/utilities/dominion-billing-history.*`.
- **Utility portal pay (link, don’t merge):** Keep `utility_bills` / `utility_bill_splits` as the obligation source of truth. Tenants pay open shares from **Payments** via `payment_type='utility'` (`src/services/utility-portal-charge.service.js`). Balance exposes `utilityDue` + `utilitySplits`. Failed Stripe util payments clear `payment_id` so tenants can retry. Manager Utilities must not expose landlord ACH charge buttons.
